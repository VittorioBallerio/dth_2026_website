# An Open Source Project for European Studies: Voyant Tools

Voyant Tools is an open source, web-based platform for reading, analysing and visualising digital texts. It was originally developed by digital humanities scholars Stéfan Sinclair and Geoffrey Rockwell. Today, Geoffrey Rockwell leads the project, supported by programmer Andrew MacDonald and other collaborators.

For a European Studies student, Voyant can be useful for analysing political language and institutional documents. For example, I could compare European Commission speeches about migration from different years. By examining word frequencies and patterns, I could investigate whether the language used to discuss migration, integration and human rights has changed over time. This would provide useful evidence for a research project, although the results would still require interpretation.

The project has several important characteristics. First, its source code uses the GPL-3.0 licence, which allows users to run, study, modify and redistribute the software under certain conditions. Second, the latest commit I found on GitHub was dated 20 October 2026. Third, the Contributors page shows several developers, although most contributions appear concentrated among a few individuals, particularly Andrew MacDonald and Stéfan Sinclair. Fourth, GitHub shows open issues, including bug reports assigned to developers, but some do not receive visible public responses. Finally, the project is supported through the Voyant Consortium, which seeks contributions from universities, research projects, institutional partners and donations rather than relying on one clearly identified funder.

Overall, I would consider Voyant a useful tool for a thesis, especially for exploratory text analysis. However, I would not depend on it exclusively. I would keep copies of my original documents and results and use other methods when necessary. This would allow me to leave the platform without losing my research.
